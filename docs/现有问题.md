# 建议
- 执行批量任务时必须有子进度条，也就是Agent 执行过程控件中进度条必须有双重进度条，用户才会知道自己的进度进行到哪里了，用户心里有底
- agent完成任务、询问用户、出现错误等对话中断或堵塞对话的情况，都需要调用windows原生通知去通知用户，还需要有通知音效
- 当一个任务批量进行时，还要告诉用户是多少个任务批量进行
- 当一个任务运行时间过长时，agent要安抚用户
